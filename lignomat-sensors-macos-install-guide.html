Install Lignomat Sensors on macOS

Install the app from the downloaded disk image (.dmg).

1. Open the disk image

When the download finishes, open your Downloads folder and double-click the Lignomat Sensors .dmg file. A Finder window will open.

2. Copy the app to Applications

In the Finder window, drag Lignomat Sensors onto the Applications folder. Wait for the copy to finish.

3. Eject the disk image

In Finder's sidebar, click the eject icon next to the Lignomat Sensors disk image. You can then close its window.

4. Open the app

Open your Applications folder and double-click Lignomat Sensors.
