  1. Download the Installer: Bypassing the browser warning.

    Browsers like Google Chrome often flag newly released software as an "uncommon download" simply because it hasn't been downloaded by thousands of people yet.

    • Click the Downloads icon at the top right of your browser window.
    • If you see a warning that the file is "not commonly downloaded" or "suspicious," hover over the blocked file and click the three dots (or right-click).
    • Select Keep.
    • If a red warning page appears, click Continue anyway to finalize the download.
  2. Launch the Setup File: Clearing Microsoft Defender SmartScreen.

    When you double-click the downloaded setup file, Windows may intercept it with a blue "Windows protected your PC" screen. This is Microsoft Defender SmartScreen pausing an app it hasn't seen before.

    • Click the More info link located just under the main text.
    • Verify the app name, then click the Run anyway button that appears at the bottom of the window.
  3. Authorize the Installation: User Account Control (UAC).

    Before the installation can begin, Windows requires administrative permission to let the app write files to your hard drive and create shortcuts.

    • A prompt will appear asking: "Do you want to allow this app to make changes to your device?"
    • Click Yes. The installation wizard will now open and guide you through the rest of the setup.

3. Windows 11 SmartScreen Dialog

4. Windows 10 SmartScreen: Unsigned App Example

These direct Windows 10 screenshots show the SmartScreen warning and its More info flow. The same warning may appear before launching a downloaded installer that is unsigned, unrecognized, or has not built a reputation. These examples show the security prompt, not the Lignomat setup wizard; wording and displayed details can vary by Windows version.

Step 1: Initial warning

Windows protected your PC appears, with More info available to reveal the publisher and app details.

Step 2: Find the More info link

The source's annotated screenshot points to More info. Click it to see the app name, publisher, and the option to continue.

Step 3: Review the publisher and choose Run anyway

After More info, Windows shows the file name and publisher. Continue only if you trust the download and have verified it came from Lignomat.
