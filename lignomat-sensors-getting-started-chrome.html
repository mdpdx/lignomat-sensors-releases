Lignomat Sensors App - Getting Started

Guide Version 4 | Windows 11 / Windows 10 (64-bit) | Google Chrome

Download this guide as PDF | Download instructions | Using Microsoft Edge? | Windows installation

Use this guide to download the Windows installer, respond to the prompts you may see, and open Lignomat Sensors for the first time. You will need administrator permission to install the app and its included BL2 USB driver.

Installation overview:
  1. Choose the guide for the browser you use. This guide is for Google Chrome.
  2. Download the installer and allow the download if prompted.
  3. Allow Windows to open the file and install the app.

Some warnings may not appear, depending on your settings and browser version. If a pictured warning does not appear, continue to the next applicable instruction.

Before you continue: Only keep or run an installer you intentionally downloaded from the Lignomat download page linked below. If the source or file name is unexpected, cancel and contact Lignomat. Do not turn off browser or Windows security protection.

Google Chrome: download the Windows installer

1. Open the download page and choose Windows

In Google Chrome, go to https://mdpdx.github.io/lignomat-sensors-releases/. Under Windows, click the blue Download button for the available version.

Google Chrome: open the downloaded installer

2. Wait for the download to finish

Chrome may show a completion popup below its download arrow near the top-right corner. Wait until the installer entry says Done.

No Chrome download warning is shown in this captured path. Chrome may show different warnings on another computer or release. If it blocks the file, review the source and message before proceeding; do not turn off Safe Browsing. Windows SmartScreen, shown later, is separate from Chrome's download checks.

3. Open the completed installer

Click Chrome's Downloads arrow to open Recent download history, then click the completed installer's file name to open it. The folder icon beside the entry lets you locate the file in Windows if you prefer to double-click it there.

Continue with the Windows steps below. You do not need to download the installer again.

Windows: review SmartScreen if it appears

Windows 1. Select More info

If Windows displays Windows protected your PC, Microsoft Defender SmartScreen has paused an unrecognized app. This is a Windows prompt, not an Edge or Chrome download popup. Click More info to review the app details.

Windows 2. Review the app, then choose Run anyway if trusted

Check that the App name matches the installer you downloaded. Unknown publisher does not establish that a file is safe. Choose Run anyway only for your intended, trusted download; otherwise choose Don't run. If Run anyway is unavailable, ask your IT administrator for help.

Windows: approve installation permission

Windows 3. Approve User Account Control (UAC)

Windows may ask, “Do you want to allow this app from an unknown publisher to make changes to your device?” Check the installer name again, then click Yes only if this is the download you intended to run. A standard user account may need an administrator to enter credentials.

Windows 4. Start the manual installation

When you run the installer manually, it shows Ready to Install. Click Install to begin. This is different from an update started inside the app: the app runs the same installer in silent mode, skipping the wizard pages and showing installation progress instead. Windows permission or installation errors may still require your attention.

Install Lignomat Sensors

Windows 5. Allow setup to prepare

Setup may briefly display Preparing to Install. Leave the window open while it prepares the installation. This screen may pass quickly before the progress bar appears.

Windows 6. Wait while setup installs the app

Leave the setup window open while the progress bar moves. Setup copies the application files and installs the included BL2 USB driver. Avoid clicking Cancel unless you intend to stop installation.

When installation succeeds, setup closes and launches Lignomat Sensors. It also creates a desktop shortcut and a Start menu entry so you can open the app later.

First launch: find your devices

Windows 7. Choose how to connect your Lignomat devices

On a first run, the app may show a Find Lignomat Devices dialog. Before scanning, make sure your RX or KDM equipment is plugged into the computer and powered on.

  • Scan for Devices: Let the app help find connected equipment.
  • Let Me Choose a Port: Choose the connection port yourself if you already know which one to use.
  • Cancel: Dismiss the dialog if you are not ready to connect devices. You can return to the Devices page and use Find, Add or Change later.

If you need help

If installation fails or the app does not open, note the exact message, installer version, and step where it stopped. Contact Lignomat through https://lignomatusa.com/. For administrator permissions or organization-managed security blocks, contact your IT administrator.
